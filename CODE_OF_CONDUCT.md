# Code of conduct

Agent RuleTrace welcomes constructive participation from people of every
background and experience level.

## Expected behavior

- Be respectful, specific, and patient.
- Critique ideas and code, not people.
- Make room for questions and different levels of expertise.
- Protect private repository data and remove sensitive information from reports.
- Accept maintainers' decisions about project scope and documented evidence.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized attention, deliberate
intimidation, doxxing, publication of private instruction content, and sustained
disruption are not acceptable in project spaces.

## Enforcement

Report conduct concerns privately to the maintainer through the contact method
on the maintainer's GitHub profile. Reports will be handled as confidentially as
practical. Maintainers may edit or remove content, issue warnings, temporarily
restrict participation, or permanently ban participants when necessary.

This policy applies in repositories, issues, pull requests, discussions, and
other spaces where someone represents the project.
